# 情境式决斗界面设计

## 目标

把当前“左侧详情 + 中央场地 + 右侧永久操作栏”改成以战场为唯一主体的
全屏界面。信息层级参考《游戏王：大师决斗》的操作习惯，但继续使用项目
自己的黑白视觉、真实卡图和简体中文，不复制其美术资源、图标或界面纹理。

本轮只重构已有原型能力的呈现方式：手牌选择、通常召唤、怪兽盖放、魔陷
盖放、发动入口、结束回合、重新开局、退出和诊断信息。尚未接入 OCGCore
语义接口的战斗、连锁候选、效果目标和多区域选择不制作假交互。

## 默认布局

- 中央战场扩展到全屏主体，双方五个怪兽区和五个魔陷区以中线镜像排列。
- 对手手牌贴上边缘呈牌背扇形，玩家手牌贴下边缘呈轻微扇形。
- 双方 LP、卡组、手牌、额外、墓地和除外统计分别放在左下角和右上角，
  不再占用中央场地的纵向行。
- 当前玩家与阶段显示为战场右侧的圆形阶段控件。
- 设置/重新开局、信息、退出收进右下角三个紧凑圆形按钮。
- 默认状态不显示卡片详情和动作按钮，最大化可读场地面积。

## 卡片详情

卡片详情改为覆盖在战场左侧的浮层，不参与根布局宽度分配：

- 鼠标悬停卡牌时临时打开详情；移开且没有锁定卡牌时自动关闭。
- 点击玩家手牌后锁定详情，并以边框标出所选卡。
- 再次点击所选卡、点击场地空白或执行“取消”时解除锁定。
- 浮层包含卡名、真实卡图、种类和可滚动效果文字。
- 对手隐藏卡不允许打开真实详情。

## 情境式动作

选中玩家手牌后，界面从当前 OCGCore `idle_actions` 中按
`controller + location + sequence + card_id` 精确筛选候选：

- 合法动作以横向胶囊按钮显示在所选手牌上方。
- 只显示后端真实提供的通常召唤、怪兽盖放、魔陷盖放和发动效果。
- 提交动作后立即清空选中和动作条，再使用新的 OCGCore 快照刷新场面。
- 没有合法动作时仅保留锁定详情，不显示“当前没有可执行动作”占位按钮。
- 每次后端快照更新都销毁旧动作条，继续防止跨回合陈旧索引。

## 阶段与系统操作

- 阶段圆球显示“玩家1/玩家2”和“主要阶段”。
- 本地玩家处于可结束回合的空闲阶段时，点击阶段球弹出紧凑确认：
  “结束回合 / 取消”；确认后调用现有 `submit_end_turn()`。
- 对手回合或规则处理中阶段球禁用，不暴露无效操作。
- 右下角“设置”按钮在本轮只弹出“重新开局 / 取消”，不制作空设置页。
- 信息按钮切换现有 F1 诊断浮层；F1 快捷键继续有效。
- 退出按钮弹出“退出游戏 / 取消”，确认后调用现有安全退出流程。

## 组件边界

- `DuelBoard` 负责全屏空间布局、浮层状态、选中状态和信号。
- `HandView` 负责手牌扇形/横向排列以及悬停、离开、点击事件。
- `CardView` 负责单卡的显示、牌背、选中高亮和指针事件。
- `Main` 继续只负责桥接 OCGCore、构造快照和处理语义动作，不保存界面状态。

快照增加明确的 `can_end_turn` 和 `local_player_turn` 布尔值，使阶段控件无需
根据中文文本猜测是否可操作。

## 失败处理

- 后端拒绝动作时，顶部中央短暂显示中文状态提示，场面保持当前权威快照。
- 没有卡图或读取失败时显示黑白占位卡，不阻断选择。
- 非本地玩家回合不显示任何手牌动作。
- 所有确认浮层均支持点击取消或点击浮层外关闭。

## 验收

- 1920×1080 逻辑画布和当前显示器原生全屏下不再存在右侧永久操作列。
- 默认画面只包含战场、双方状态、阶段球、手牌和右下角紧凑工具按钮。
- 悬停手牌显示详情，移开关闭；点击后详情锁定。
- 点击有候选的卡只显示该卡真实合法动作，召唤或盖放后场面正确更新。
- 阶段球可确认结束回合，对手回合不可误触发本地动作。
- 重新开局、信息、退出均通过紧凑确认或浮层工作。
- 原生测试、Godot 无头启动、Godot MCP 截图与交互检查全部通过。
