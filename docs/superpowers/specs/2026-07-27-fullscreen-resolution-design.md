# 全屏与多分辨率适配设计

## 目标

决斗原型默认使用当前显示器的原生分辨率全屏运行，并以 `1920×1080`
作为界面设计基准。后续在 2K、4K 或其他尺寸显示器上运行时，决斗场继续
由 Godot 容器和 `canvas_items` 拉伸机制分配空间，不依赖固定屏幕坐标。

## 窗口策略

- `project.godot` 的设计 viewport 改为 `1920×1080`。
- 默认窗口模式改为独占全屏，实际渲染尺寸由当前显示器决定。
- 保留 Godot 启动参数覆盖窗口模式的能力，供编辑器和 MCP 使用
  `1920×1080` 窗口验收。

## 布局策略

- 根节点继续使用全屏锚点和三栏容器。
- 左右信息栏采用 1080P 下更宽的最小宽度，中间决斗场扩展填充剩余空间。
- 卡图、手牌、场地区域和文字同步增大，但不将节点绑定到绝对屏幕坐标。
- 非 16:9 屏幕由容器吸收额外空间，功能节点不得裁切或重叠。

## 退出流程

右侧操作栏增加“退出游戏”按钮。按钮发出独立信号，由主场景调用
`get_tree().quit()`；主节点退出树时沿用现有逻辑销毁活动决斗，保证
OCGCore 生命周期完整结束。

## 验收

- 项目配置的设计分辨率为 `1920×1080`，默认全屏。
- Godot MCP 截图尺寸为 `1920×1080`。
- 双方手牌、场区、状态栏、卡片详情和操作栏完整可见。
- “退出游戏”按钮存在且连接退出回调。
- 原生测试、Godot 无头启动和运行期错误检查均通过。
